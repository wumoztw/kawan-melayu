# 第一至三天試玩指引

## 自動化環境

```bash
npm install
npm run dev
```

開啟 Vite 顯示的本機網址。此版本目前是離線規則試玩版，首頁直接進入當日簡報。

## 遊玩流程

1. 按「開始營業」或鍵盤 `1`。
2. 閱讀顧客的馬來文句子與華語提示，再按答案選項；`1`–`4` 可用鍵盤選擇。
3. 答對會扣除進貨成本、增加售貨收入、經驗、聲望並複習單字；答錯不會得到答對獎勵。
4. 資金不足無法補貨時，選「缺貨」記錄未能供應。
5. 「儲存進度」會將狀態寫入瀏覽器 localStorage。重新載入後載入狀態。
6. 第 2、3 天由規則提供顧客與補貨；按「Mak Cik 幫助」後可看到旗標對話。
7. 第 3 天結束後顯示試玩結束畫面。

## 測試範圍與已知限制

自動化證據：`tests/e2e/day1.test.js` 測引擎情境；`tests/e2e/app.test.js` 以 jsdom 驅動畫面 DOM、鍵盤與 localStorage。這些不是 Playwright/真實瀏覽器測試。UI 使用選擇題，目前沒有自由輸入欄位，也尚未完成 30 日劇情／考試流程。本試玩版本未經母語者審閱，馬來文內容不可視為教學定稿。
